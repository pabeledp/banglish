Security Guide

Phonetic Typing Guide & Key Chart (টাইপিং গাইড ও বর্ণ চার্ট)

যুক্তাক্ষর তৈরি (Conjuncts)

দুটি ব্যঞ্জনবর্ণের মাঝে স্বরবর্ণ না দিয়ে পরপর লিখলেই স্বয়ংক্রিয়ভাবে যুক্তবর্ণ গঠিত হয়।

k + t → ক্ত (rokti → রক্ত)
s + t → স্ত (rasta → রাস্তা)
b + d → ব্দ (shobdo → শব্দ)
2

ফলা ও বিশেষ রূপ (Modifiers)

য-ফলা, র-ফলা, রেফ ও ব-ফলা লেখার সহজ নিয়ম:

y / Z → ্য (bakya → বাক্য)
r / rr → ্র / র্ (gram → গ্রাম, kormo → কর্ম)
w / b → ্ব (shwadhin → স্বাধীন)
3

টগল শর্টকাট (Toggle Shortcut)

ম্যাকের যেকোনো অ্যাপে টাইপ করার সময় বাংলা ও ইংরেজির মধ্যে দ্রুত অদলবদল করুন:

⌥ Option + Space

অথবা সিস্টেম ডিফল্ট Ctrl + Space ব্যবহার করুন।
